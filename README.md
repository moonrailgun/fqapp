# Cached reading resume demo

Android 14 emulator recordings of fqapp commit `4d07e80efc4cb41afca87ae1175f9bd97cd4de6f` (debug build, version 1.0.127+132).

- `home.mp4`: tap the recent-reading card, resume the saved chapter, return to Home.
- `shelf.mp4`: tap the saved book, resume the same position, return to the shelf.
- GIF files are resized copies for inline PR previews; the MP4 files are the original recordings.

The source change lives on `feat/cached-novel-resume`. This branch stores demo media only.
